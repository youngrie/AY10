## 维护约定

- `tasks.md` 是**唯一的进度来源**：做完一项把 `[ ]` 改成 `[√]`，
  并在下面补一行实测结果（便于写报告时引用）。
- 新增任务时按 `A-` / `B-` / `C-` 归类，与模块边界一致
  （A 管 `nets/` + `src/env/`，B 管 `src/agents/`，C 管基线与评估）。
- 涉及"当前状态"的描述（车道数、动作数、观测维度、实测数字）过时了要及时改，
  否则会误导组员。
